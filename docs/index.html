CSV Upload Format Guide
Overview

Upload a CSV file where each row represents one (technique, dataset, backbone, refinement, spc) combination. Multiple rows with the same combination are averaged automatically by the Python helper. The tool reads the mean and std to display X.X ± Y.Y values.

Required Columns
Column Type Description
technique string SSL / supervised method name (e.g. TFC, Diet)
dataset string Target dataset abbreviation (e.g. KH, UCI)
backbone string Encoder name (e.g. ResNet-SE-5, RNN)
refinement string freeze or full_finetuning
spc integer Samples per class: 1 5 10 25 50 100 200 1000 (1000 = 100% dataset)
mean float Mean accuracy in % (0–100)
std float Std deviation in % (0–100); use 0 if single run
Example CSV
technique,dataset,backbone,refinement,spc,mean,std TFC,KH,ResNet-SE-5,full_finetuning,1,41.9,2.8 TFC,KH,ResNet-SE-5,full_finetuning,5,53.7,5.3 TFC,KH,ResNet-SE-5,full_finetuning,10,51.4,9.1 TFC,KH,ResNet-SE-5,full_finetuning,25,64.4,6.8 TFC,KH,ResNet-SE-5,full_finetuning,50,65.7,0.3 TFC,KH,ResNet-SE-5,full_finetuning,100,62.7,2.0 TFC,KH,ResNet-SE-5,full_finetuning,200,66.4,0.3 TFC,KH,ResNet-SE-5,full_finetuning,1000,68.8,3.0 # You don't need all 8 spc values — missing ones show as N/A MyMethod,UCI,RNN,freeze,1,55.1,1.2 MyMethod,UCI,RNN,freeze,1000,78.3,0.9
